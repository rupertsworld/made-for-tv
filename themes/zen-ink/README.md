# Zen Ink

A paper-and-ink theme for Television: washi-paper surfaces, sumi-ink text and a single vermilion accent like a hanko seal, over a soft dusk gradient. It follows the light and dark appearance setting of Television. Dark reverses paper and ink.

## Install

Copy this folder into the themes folder of Television, which `tv themes-path` prints, then select the theme:

```sh
tv set-theme zen-ink
```

## Decisions

- **Light and dark.** Light is ink text on warm paper. Dark is paper-white text on ink-black sheets. In light, the ink and greys carry a faint violet undertone taken from the top of the light wallpaper; in dark, the sheets and greys carry the olive undertone of the top of the dark wallpaper. The manifest declares `light dark`, and the colours that differ are in the `[data-theme="light"]` and `[data-theme="dark"]` blocks.
- **Accent used sparingly.** `--accent` is vermilion and drives primary buttons and focus rings. The selected channel uses a pill in the text colour instead (ink in light, paper in dark), and checked tasks use ink, so the red appears rarely. In dark the vermilion is a step lighter so it holds against the ink.
- **Sheets.** Artifact frames use a titlebar in the same colour as the sheet and a soft, wide shadow. Corner radii are left at the Television defaults.
- **Tabs and controls on the wallpaper** use the text colour over a white wash (`--wallpaper-overlay-background`): 40% in light and 9% in dark. The wash makes them read as controls rather than loose text. Hover and press derive from it automatically.
- **Channel switcher.** The channel switcher in the top bar sets its own selected-channel colours, which hide the colours this theme sets at the root. The `.channel-switcher-pop` rule sets the pill colours there too, so a selected channel looks the same in the switcher as in the sidebar.

## Wallpapers

- Each wallpaper is a two-colour CSS gradient set as `--app-wallpaper`. Light runs from mauve-grey at the top to sage-grey at 60% of the height, then stays sage-grey. Dark stays olive ink-black for the top 30%, then opens into slate blue-grey at the bottom.
- A grain texture is tiled over each gradient: `assets/grain-light.png` and `assets/grain-dark.png`, generated by `make-grain.py`. Each pixel of a texture is white or black at a low opacity, so the grain varies the colour by about one level out of 255 without lightening or greying the gradient. The two textures differ only in opacity, which is set for the typical colour beneath each one.
- The texture is set through `--app-wallpaper-image`, because Television resolves a relative URL against the theme stylesheet only in that token.

## Maintenance

- Colours: shared values are in `:root`. The accent, surfaces, text and shadows for each appearance are in the light and dark blocks. The accent and neutral are single values; Television generates their scales.
- App-only treatments (wallpaper, selected channel, frames, tabs) are in the `[data-television-document="app"]` block, with dark differences in the block after it.
- Wallpapers: edit the two colours and their positions in `--app-wallpaper`. To change the grain, edit `GRAIN_LEVELS` or the typical colours in `make-grain.py` and run it with Python and Pillow.
- No JavaScript.
